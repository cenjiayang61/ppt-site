从好看进入有叙事

新店不是一次空间更新，而是一次品牌语境的转向。

目前小西家作已经具备东方、高级、油画、礼赠、温柔、长情、剧场感等气质关键词，但这些词仍然偏向感受描述，需要一个能够统领产品、空间、物料、陈列和文案的品牌母题。

万象城店的核心任务，是让顾客在门店中感受到：产品不是被售卖的商品，而是被温柔呈现、可以带回家的作品与心意。

03 / 28

品牌母题

可以带回家的
东方生活静物

这句话同时解释产品、空间、物料、陈列和文案。

它把原有“时光温软，长情陪伴”的气质，落到具体可感知的物件与场景中。蛋糕不只是甜品，而是日常关系中的一份温柔作品；门店也不只是零售空间，而是一间可以停留、观看、选择、带走心意的东方甜点客厅。

04 / 28

核心叙事拆解

家与作：情感温度与审美分寸

家

不是家庭感的土味，而是客厅、陪伴、礼物、心意，以及日常里的仪式。

它让蛋糕从一次消费，变成可以被带回关系里的温柔片段。

作

不是普通烘焙，而是手作、笔触、作品、时间与审美。

它让产品从“好吃”，进入“被创作、被观看、被珍藏”的语境。

05 / 28

论述体系总览

从产品灵感，到空间观看，再到礼赠带走。

花事入糕花卉、季节、东方风物成为产品的感官来源。
奶油成画蛋糕表面像油画笔触，是手作的直接证据。
手作成礼用小卡、书签、随礼纸品把产品转译成心意。
客厅成境陈列柜、深木桌、低照度，形成可停留的观看场。
日常成陪伴把生日、开业、节气与日常关系纳入品牌语言。
06 / 28

五个感官锚点

把抽象调性，变成可被设计、可被陈列、可被拍摄的物件。

花东方花事、季节植物、植物图谱，是产品和纸品的灵感入口。
笔触奶油纹理、油画质感、手作痕迹，让蛋糕成为可观看的作品。
纸艺术印刷纸、书签、小卡、期刊，把产品转译成可以被收藏的心意。
光低照度、暖光和暗场留白，让物件被认真看见。
器花器、托盘、陈列柜、深木桌面，建立东方客厅的观看秩序。
07 / 28

奶油成画

让产品表面成为品牌最直接的视觉语言。

东方油画蛋糕不是单一新品，而是品牌转型的入口：它把“手作”从工艺说明，变成顾客一眼可以识别的笔触、色层与时间感。

后续平面、陈列、文案都可以围绕“像一幅可以食用的静物画”展开。

08 / 28

东方花事

花卉不是装饰，而是产品、纸品与空间共同的灵感档案。

09 / 28

手作成礼

让小卡、书签与随礼纸品，替产品说完那句温柔的话。

物料不只承担信息说明，也要承担“礼”的情绪。它应该像被认真挑选后夹在蛋糕旁边的一张纸，轻、薄、克制，却能让顾客感到这份心意被完成了。

开业赠礼、生日礼盒、季节限定，都可以用同一套纸品系统承接。

10 / 28

客厅成境

陈列柜不是货架，而是甜点与纸品的收藏柜。

空间可以借鉴客厅式陈列：少量产品、花器、纸品、框画与暗场留白共同出现。产品不被堆满，而是被留出观看距离。

这一点能让小西家作从烘焙店的售卖逻辑，过渡到生活方式品牌的停留逻辑。

11 / 28

柔光观看

低照度不是昏暗，而是让物件被认真看见。

深木桌、暖光、暗场、少量产品与留白，可以把甜点从“陈列商品”转译成“桌面静物”。

画面中不需要很多蛋糕，反而需要足够的安静，让纸、花、器和蛋糕形成关系。

12 / 28

平面视觉语言

留白、纸感、细字、局部花卉，构成小西家作的新物料语气。

版式原则

文字少而准，像手记、菜单、花事笔记；页面更闲散，不做信息堆叠。

高级感来自纸张、比例、装订、低饱和色与空白，而不是过度手工拼贴。

13 / 28

花卉笔触图谱

把新品开发、包装图案与文案灵感放在同一张图谱里。

14 / 28

作品标签

产品小卡要像艺术印刷纸，安静地放在产品侧方。

小卡不需要解释太多，只需说明作品名、花卉灵感、口味结构与一句短句。呈现方式应靠近“展签”，而不是促销牌。

建议使用厚质艺术纸、微纹理纸、压凹或局部专色；文字以窄栏排布，保持小而精确。

15 / 28

生活场景版式

产品与物料一起出现，但画面要少、稳、准。

16 / 28

品牌刊物

《小西花事》可以成为新店的核心内容容器。

它不需要做成密集杂志，而更像一本闲散手记：一页花卉灵感，一页产品笔触，一页生日礼物，一页空间片段。

刊物承担品牌调性统一的功能，也可以作为开业、节气、新品、会员礼的长期内容模板。

17 / 28

新店开业随礼小卡

一张卡完成欢迎、祝福与品牌第一印象。

内容方向

“今日花信”“万象城店限定”“把一份花事带回家”等短句，可以让开业动作从促销转为礼赠。

卡片可与试吃、限定甜品、花枝或包装丝带共同出现，形成可拍摄、可带走的记忆点。

18 / 28

花草明信片系列

把每一款蛋糕背后的花与季节，做成可以收藏的小纸片。

19 / 28

生日蛋糕礼盒随礼书签

让生日祝福从包装里被轻轻抽出来。

书签比普通卡片更有“可保存”的属性。它可以写生日花语、口味说明、祝福短句，也可以做成不同月份或不同花卉系列。

插入礼盒、夹在菜单、挂在丝带上，都能让产品多一层“被赠予”的仪式感。

20 / 28

墙上挂画与文字信息

墙面不做口号，而做一组可以被阅读的品牌注脚。

可采用框画、展签、窄幅文字与花卉图谱的组合。内容围绕“花事、笔触、家作、礼赠”展开，不直接解释品牌升级，而是让顾客在停留时自然读到。

文字宜短、疏、克制，像作品说明或小型展览说明。

21 / 28

陈列柜策略

用少量产品、纸品和器物形成“被收藏”的状态。

22 / 28

深木桌与低照度桌面

桌面要像一处小型静物台，而不是产品堆叠区。

推荐组合为：一个主产品、一张产品小卡、一件器物、一枝植物或一张纸品。通过低光、深木、玻璃或陶瓷，让材质层次成为高级感来源。

这种桌面适合拍摄开业视觉、会员礼、生日礼盒与社交媒体内容。

23 / 28

花器、植物与东方花事

植物不做满铺装饰，只在关键节点成为叙事线索。

使用原则

花器偏低、枝叶偏疏、色彩偏柔，和蛋糕色系形成呼应。植物用于连接“东方花事”和“生活静物”，而不是制造花店感。

24 / 28

软装与物料整合方式

不是把物料摆进去，而是让每类物料都有自己的场景角色。

入口

开业卡、花事小卡、当季主题，建立第一眼的品牌语气。

陈列

产品小卡、花卉图谱、展签，让顾客理解蛋糕像作品一样被陈列。

带走

书签、明信片、随礼卡，把门店体验延伸到家中与赠礼关系里。

25 / 28

执行优先级

先建立能被顾客看见和带走的核心物料，再扩展完整内容系统。

第一阶段产品小卡、开业随礼卡、生日礼盒书签、陈列展签。
第二阶段花草明信片、墙面框画、桌面花器与纸品组合。
第三阶段《小西花事》小刊物、季节专题、会员礼与长期内容栏目。
26 / 28

最终落点

把花、光和心意，
做进一块蛋糕里。

小西家作的新店叙事，不是更会装饰，而是让产品、纸品、陈列和空间一起说同一种温柔而高级的话。
